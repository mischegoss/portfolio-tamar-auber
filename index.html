How I Work

I'm a technical writer and documentation engineer. I build AI-powered documentation tooling, and I write the docs that run on it.

I treat documentation as a product: tested, versioned, and improved the same way software is.

  • I own docs-as-code infrastructure end to end: Docusaurus, Git, CI/CD pipelines, and custom React components. In 2025 I maintained three production sites that served 226k+ user sessions with zero disruptive downtime.
  • I build and ship AI-powered self-service tools in Python on Google Cloud. I've shipped seven chatbots: four iterative improvements to a vendor solution, then three custom-built RAG replacements now in production. The custom bots reduced support escalations by 30% and cut the fail rate from 27% to under 9%.
  • I write and maintain API references, integration runbooks, tutorials, and technical guides for engineers, DevOps teams, and developer audiences.
  • I optimize documentation for both human readers and AI agents, including semantic metadata, content chunking, and retrieval architecture.
  • I partner with engineering on release cycles so documentation ships alongside the features it covers.
